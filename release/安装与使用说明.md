# AI 练习室 Android 第一版

版本 1.0.7，包名 cn.aistudy.practice，支持 Android 8.0 及以上。系统 Android System WebView 需要保持更新。

## 从旧版升级

直接安装 AI练习室-v1.0.7.apk 覆盖旧版本，无需卸载。包名、签名与存储标识保持一致，以保留原答题进度、草稿、对话、笔记和 Key。建议升级前导出一份完整备份。

新版使用底部四栏：刷题、问 AI、知识库、设置。可在内容区域左右滑动切页；输入框和代码区域保留原来的编辑、滚动操作。筛选与题号导航可点开。设置分 API、题库更新、备份三个页面。切换页面会保留未提交的输入；笔记仍需点击保存才会持久保存。

## 安装与迁移原进度

1. 电脑上刷新原刷题页面 `quiz/index.html`。
2. 点击底部“设置”→“备份”→“导出完整备份”。备份包含岗位与基础选择题进度、Hot100 草稿及聊天、知识笔记，不包含 API Key。
3. 把 APK 和备份 JSON 文件发送到手机。在 Android 文件管理器中打开 APK，按系统提示安装。
4. 打开 AI 练习室，进入底部“设置”→“备份”→“导入 / 合并备份”，选择刚才的 JSON 文件。核对后点击“合并并恢复”。
5. 手机已有记录时，已有题目的答案与草稿以手机记录为准；补入其他题目，对话按消息 ID 合并，冲突笔记保留副本。

原电脑浏览器与手机存储互相独立，第一版没有云同步。安装 APK 不会修改电脑浏览器的记录。

## 刷题时直接问 AI

在选择题或算法题的操作区点击“问 AI”，底部会展开较小的对话面板，题目在上方独立滚动。输入框和发送按钮位于面板顶部，回复在下方独立滚动。拖动顶部手柄可上下调整面板高度，继续向下拖即可收起。点击“展开”阅读完整对话，点击“返回题目”恢复面板，点击“收起”继续答题。

面板默认提供“只给提示”和“解释这题”。需要附带答案、代码草稿、原题解或修改 API 设置时，点击“展开”后使用“附带内容与更多设置”。完整 AI 页面仍保留。

切题会关联该题自己的聊天和未发送输入。未发送输入在本次页面内暂存；已发送的聊天持久保存。收起面板不会停止正在生成的回答，若要取消需点击“停止生成”。可用屏幕高度变小时，面板保持紧凑，输入框仍位于面板顶部；不再自动扩大到接近全屏。

## DeepSeek API Key

进入底部“设置”→“API”，输入自己的 DeepSeek API Key，直接点击“测试连接”即可保存并检测。结果显示在按钮下方，最多等待 25 秒。Key 由 Android Keystore 中的密钥加密，存入应用私有数据库；不会作为明文写入网页存储或导出备份。API 请求由手机直接发送到 `https://api.deepseek.com`，没有中转服务器。

默认模型为 `deepseek-v4-flash`，也可以在设置中切换。模型名称及可用性以你的 DeepSeek API 账户为准。测试连接请求模型列表；聊天按 DeepSeek API 计费。没有 Key 或没有网络时，仍可以离线刷题、查看原题解和已有笔记。

选择一道题后点击“问 AI”。可以只要提示、解释题目、检查草稿或进行面试追问。发送前可选择是否附带当前答案／代码草稿，以及是否附带原题解。默认不附带原题解。对话自动保存，支持停止生成，已收到的部分仍会保留。

发送时只带题目快照和有限的近期对话，全部历史保存在本地，不会每次都发送整个知识库。题目及草稿属于发送给 DeepSeek 的内容。AI 讲解作为学习辅助，不会覆盖原题解；应用不执行用户的 Python 代码。

网页版同样有这些入口，但网页版 Key 仅放在本次页面内存中，刷新会清除；直接请求可能受浏览器跨域策略影响。APK 通过原生网络连接 DeepSeek。

## AI 学习评估

在底部“知识库”→“学习评估”中生成报告，也可从“问 AI”页面进入。先离线查看模块统计，再主动点击“生成 AI 学习评估”；使用已配置的 DeepSeek Key。

评估提交各模块题量、当前可评估题正确率、最多 20 道按模块抽样的错题及其知识点，以及算法题自评状态。不会附带个人代码草稿、聊天记录或笔记。报告包含掌握情况、知识缺口、补习顺序、自测方法与建议练习题。

每次报告自动作为知识笔记保存，并保留答题快照、日期、模型和生成状态；重新评估会新建报告，旧报告可从知识库打开对照。报告包含在完整备份中，也可导出笔记 Markdown。失败、停止或中断的报告会注明未完成，部分内容保留。

每题只有当前答案，没有首次作答、重试次数或耗时记录；因此不会推断学习速度。修订答案与历史判分不一致的题目不计入当前正确率；算法掌握标记仅为自评。少于 5 道可评估题的模块标为证据不足，未做题代表未测。AI 的能力判断和补习建议仍需通过后续练习验证。

## 个人知识库

AI 回复下面点击“存为知识笔记”，可以修改标题、正文、标签和掌握状态。也可以在“我的知识库”中新建个人笔记。

知识库支持搜索标题、标签、正文和对话内容，按“待理解／已掌握”筛选笔记。每条来自 AI 的笔记保留来源题目与题目快照。题目对话可从知识库中打开并继续追问。笔记修改后需点击“保存笔记”。

支持导出笔记 Markdown，以及导出／恢复完整 JSON 备份。卸载应用、清除应用数据或更换手机之前，请先备份。Android 自动云备份在本应用中关闭；不会自动同步到其他设备。

第一版的单个备份文件上限为 16 MB；题库下载上限为 12 MB。导入的备份若携带题库，其题号集合需兼容当前已安装题库，否则会拒绝导入并保留原数据。

## 题库更新

按当前约定，第一版暂不预设在线托管地址。提供两种方式：

- **导入题库包**：选择附带的 `题库包-2026.09.09.1.json`，或以后发布的新题库 JSON，校验后安装。
- **在线检查更新**：设置一个直接返回题库 JSON 的 HTTPS 地址，点击“检查更新”。APK 不跟随跳转，地址应直接返回文件，不能是网页分享链接。网页版本还要求托管端允许跨域读取。

应用先下载并校验整个包，再原子替换。下载失败或格式错误时不修改已有题库。题库包仅包含数据，不会执行远程 JavaScript。已有题号不能删除或被重新用于另一道题，草稿、对话、笔记与答题记录分别保存。

如果正确答案发生修订，保留当时的判分，提示重新作答。新增题目或修订解析无需重新安装 APK；新增交互题型或原生功能仍需要应用升级。

## 后续构建与更新

题库发布脚本是 `quiz/publish_bank.py`，将两份源 JSON 生成完整题库包。发布新题库时修改版本号和更新说明，把 JSON 上传到自己的 HTTPS 静态托管地址。

网页生成脚本是 `quiz/assemble.py`；Android 源码位于 `quiz/mobile/src`，APK 构建脚本是 `quiz/mobile/build_apk.py`。

应用更新必须保持包名及签名密钥一致并递增 versionCode。签名材料保存在本机 `quiz/mobile/signing`，已加入 Git 忽略；请妥善备份，不要分享该目录。保留这套签名材料后可继续生成覆盖安装的升级包。卸载再重装不能视为保留进度的方法。

## 验证范围

已完成 APK 编译、包结构和签名校验；原题库回归、AI 模拟流式回复与错误处理、知识笔记、备份恢复、题库更新和 Android 存储桥接契约测试。

构建环境没有连接 Android 真机，尚未完成真实设备上的安装、Keystore、系统文件选择器和网络联调。也没有使用真实 API Key 发起付费调用。首次使用请按上面的“测试连接”步骤验证你的网络和账户。

## 基础认知题库

刷题页顶部选择“AI 基础认知”：300 题，10 章各 30 题，240 单选、60 多选。提交后可看逐项解释、简单例子与参考资料。与原题库分开保存进度，错题、收藏、问 AI、完整备份和学习评估均已接入。旧 APK 请先覆盖安装 v1.0.5；以后题目内容可使用固定 bank.json 地址更新。

## 企业智能决策专项

覆盖安装 v1.0.6 后，在刷题页顶部选择“企业决策”。共 210 题、7 章，独立记录进度。原岗位、Hot100 与基础认知题库保留。支持本题问 AI、错题、收藏、学习评估及备份；专项备份请在 v1.0.6 或更新版本恢复。

## v1.0.7 题库侧边栏与公式

顶部“☰ 题库”打开侧边栏，选择题库后收起。题目、解析与 AI 回复支持 LaTeX，公式引擎和字体已内置，可离线显示。升级请覆盖安装，不要卸载。

题目内容可以通过“设置 → 题库更新”填写 https://llh-astro.github.io/ai-study-room/bank.json 后检查并安装更新。功能变化需要升级 APK；以后只改题目无需重装。自建题库详见仓库 BANK_FORMAT.md、custom-questions.example.json 与 build_custom_bank.py。
